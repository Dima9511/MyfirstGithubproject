My Practice Sandbox is a test automation repository designed to practice local environment setup and version control workflows. 
The project involves pulling code from GitHub, running and debugging scripts locally via Visual Studio Code, and pushing the finalized updates back to the remote repository. 
Through this project, I mastered the core fundamentals of Git version control (cloning, pulling, and pushing repositories), local execution troubleshooting, and managing a seamless local-to-remote development environment.
